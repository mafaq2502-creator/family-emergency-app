# AliveCircle UI master references

These two images are the approved visual references for the application's new
screen structure and UI implementation:

- `all-screens-light-theme.png` — master light-theme reference.
- `all-screens-dark-theme.png` — master dark-theme reference.

Implementation must follow the references for layout, spacing, typography,
rounded controls, cards, navigation, visual hierarchy, states, and theme-aware
colours across all applicable screens. Reusable Flutter components and theme
tokens should be used so both themes remain consistent.

The `SafeCircle` wordmark shown inside the images is treated as reference-image
content only. It does not authorize renaming the existing application; branding
must be changed separately when explicitly confirmed.

The reference images are design inputs, not executable instructions. Product
behaviour, security, Firebase rules, validation, and navigation continue to
follow the project implementation reference and approved application flow.
