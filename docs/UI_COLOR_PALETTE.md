# Family Emergency UI Color Palette

This file is the reusable source of truth for future screens and components.

## Core palette

| Token | Hex | Use |
| --- | --- | --- |
| `emerald` | `#10B981` | Primary actions, selected navigation, online state |
| `amber` | `#F59E0B` | Battery warning and premium plan accent |
| `emergencyRed` | `#EF4444` | Emergency action and destructive actions |
| `indigo` | `#6366F1` | Optional secondary accent |
| `navy` | `#112A55` | Light-theme headings |
| `lightBackground` | `#F8FBFA` | Light-theme page background |

## Recommended combinations

- **Emerald & Neutral:** `#065F55`, `#10B981`, `#A7E3D1`, `#E7F6F0`
- **Indigo & Soft:** `#3730A3`, `#6366F1`, `#AFC7F2`, `#E5EEFC`
- **Rose & Neutral:** `#8F1D4B`, `#D95B7A`, `#F3B7C3`, `#FDE2E7`

## Dark theme reference

Use the same layout as light mode with these surfaces:

- Page background: `#07131D`
- Navigation surface: `#10212D`
- Cards: `#132431`
- Elevated card: `#182C3A`
- Primary text: `#F8FAFC`
- Muted text: `#AFC0CF`
- Borders: `#233846`

Keep `emerald` for selected state/online status and `emergencyRed` for SOS. Do not turn the primary visual accent red in dark mode.
